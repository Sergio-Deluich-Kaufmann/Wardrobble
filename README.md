# Wardrobble

A local-first outfit shuffler that helps you beat daily decision fatigue. Add your clothes, shuffle an outfit in one tap, and save the ones you like.

## Features

- 👕 Add clothing items with type, color, season, and occasion tags
- 🔀 Smart shuffle — tag-based compatibility, no random noise
- 🔒 Lock items to keep them in your outfit while reshuffling the rest
- 💾 Save outfits with auto-generated names
- 🔍 Filter and search your wardrobe by type or tag
- 📱 Fully responsive — mobile, tablet, and desktop

## Tech Stack

React · Vite · Tailwind CSS · localStorage

## Run Locally

```bash
npm install
npm run dev
```
